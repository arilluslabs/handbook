These are the tools we use at Arillus by default. Every team member should be set up on all of these from day one.

| Purpose | Tool |
|---|---|
| Email | Zoho Mail |
| File storage & documents | Zoho WorkDrive |
| Docs & Sheets | Zoho (Writer / Sheet) |
| Audio / video meetings | Zoho Meet |
| Password manager | Zoho Vault |
| Git repository | Bitbucket |
| Project management | Jira |
| Team communication | Zoho Cliq |

On client projects, the tools may change based on what the client uses. That's expected — adapt as needed. The list above is the Arillus default when there's no client preference.

---

## Use Your Work Account. Always.

Never use personal accounts for work. This means no Google Docs, no Google Sheets, no Google Meet, no personal Dropbox, no personal GitHub — nothing created from or stored in a personal account.

This matters for two reasons:

1. **Ownership** — work created in a personal account belongs to you personally, not to Arillus or the client. If you leave, we lose access.
2. **Security** — client data and project information must stay within accounts Arillus controls, not personal accounts with unknown security settings or sharing history.

If you find yourself reaching for a personal account because something isn't set up on your work account, raise it — don't work around it.
